# Documentation

Vorlagen liegen in `templates/`. Kurz halten.

- **README:** Immer, ab dem ersten Tag (Vorlage `PROJECT_README.md`).
- **Concept:** Vor dem ersten Code (`CONCEPT.md`).
- **Data Model:** Sobald Daten gespeichert werden (`DATA_MODEL.md`).
- **Decision Record:** Nur bei Entscheidungen, die ich später sonst vergesse (`DECISION_RECORD.md`).
- **Kommentare:** Das Warum erklären, nicht das Was.
- **Changelog:** Optional, erst ab Version 1.0.
