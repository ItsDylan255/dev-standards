# Definition of Done

## Feature fertig
- [ ] Funktioniert im Normalfall und im Fehlerfall
- [ ] Getestet (automatisch, wo sinnvoll)
- [ ] Committed mit sauberer Message
- [ ] Keine toten Code-Reste und TODOs ohne Grund

## Release fertig
- [ ] MVP-Liste aus `CONCEPT.md` komplett abgehakt
- [ ] Auf echter Hardware/Gerät getestet
- [ ] README aktuell (Starten, Stack, Status)
- [ ] Version getaggt
- [ ] Backup von Keys, Daten und Konfiguration

## Projekt fertig
- [ ] Was würde ich beim nächsten Mal anders machen? (3 Stichpunkte ins README)
